# Python Projects

Python programs and notebooks written while learning Python on the Future Connect data analytics course (2026).

## GUI apps (`gui/`)
- `calculator.py`: Tkinter calculator
- `application_form.py`: Tkinter form with input handling

## Mini projects (`projects/`)
- `web_scraping.py`: scrapes a table of the largest US companies by revenue into a CSV
- `large_file_renamer.py`: batch renames files in a folder
- `binary_search.py`: binary search algorithm
- `rock_paper_scissors.py`, `zodiac_sign.py`: small interactive programs
- `email_to_recipients.py`: email sender outline

## Fundamentals (`basics/`)
Calculators, Fibonacci series, FizzBuzz, number guessing game, swapping values, string case swapping and an OOP example.

## Notebooks (`notebooks/`)
- `numpy_tutorial.ipynb`
- `pandas_tutorial.ipynb`
- `data_visualisation.ipynb` (matplotlib and seaborn)

## Tools
Python 3, Tkinter, requests and BeautifulSoup, pandas, NumPy, matplotlib, seaborn, Jupyter
